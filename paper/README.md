# paper/

Skeleton of the paper. Section headings and floats only; the text is the author's own, never AI-written.

## Build
From this folder: `latexmk -pdf main.tex`. The final `paper.pdf` is committed at the repository root (copy `main.pdf` there). `main.pdf` and LaTeX build files stay git-ignored.

## SIAM class (author action)
The official SIAM class is not in the repo (the SIAM site was not reachable from the AI session and a redistribution licence was not confirmed). Download the SIAM macro package from SIAM's author information page (https://www.siam.org/publications/journals/about-siam-journals/information-for-authors) and put `siamart220329.cls` (and `siamplain.bst` for references, if you use BibTeX) in this folder. If the class file is missing, `main.tex` falls back to the standard `article` class, so the build still works for a layout check. Check the licence terms before committing the files.

## Figures and tables
Every figure and table comes from `../figures/` and is regenerated by stages 03 to 05 (index: `../figures/README.md`). Never edit a `.tex` fragment or a PDF by hand; change the code and re-run. Floats carry a placeholder caption (`TODO caption (author)`).

## Length
About 10 pages, at least 8 without references.

## Tests
`tests/test_paper.py` checks that every referenced path exists, that every output in `figures/README.md` is used (or listed as not used), and that the headings follow the course order. It also has a no-prose guard: set `ENFORCE_NO_PROSE = False` at the top of that file when you start writing the text (the guard would fail on your own paragraphs).
